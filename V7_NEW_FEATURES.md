# WorldForge V7 — Homework Studio

Added five worksheet categories: continents, map skills, physical geography, climate and projects, each containing two five-prompt worksheets (10 worksheets and 50 prompts). Worksheets support typed responses, clearing, and print styling; worksheet answers are not automatically submitted or saved. Parents can copy worksheet prompts into the linked-child homework creator.

Added 31 searchable geography reference facts in five categories and a flashcard deck built from the facts. Flashcard progress is in-page only. Existing server-side homework, accounts, and quiz results are preserved.

Start with `PORT=8081 python3 server.py` from the worldforge directory. Back up any prior classroom.sqlite3 and copy it into this directory before starting if you want to retain existing accounts. Keep this local, not exposed to the public internet.
